# Operations

## Documentation Policy

Each slice must update design docs in the same PR:

- files in this `docs/design/` folder
- `apps/orchestrator/README.md`
- root `README.md` when boundaries or startup flow change
- ADRs when execution contracts change materially

## Definition Of Done

A slice is complete only when:

- behavior is implemented
- tests pass
- structured widget/data paths reject prose payloads
- docs are updated in the same task
